# Картографические артефакты

Инструменты собирают подложку и дорожный граф из локального файла OpenStreetMap.
Ни один из них не запускается в обычном CI и не выполняется при выкатке:
московский набор — это гигабайты, скачивать которые на каждую сборку незачем
и вредно. Сборка выполняется отдельной операцией, а результат кладётся
на сервер как неизменяемый набор файлов.

## Что и чем собирается

| Артефакт                         | Инструмент | Версия                            |
| -------------------------------- | ---------- | --------------------------------- |
| PMTiles + стиль, спрайты, шрифты | planetiler | `0.10.2`, digest в `versions.env` |
| Дорожный граф                    | valhalla   | `3.8.3`, digest в `versions.env`  |

Версии закреплены в `versions.env` тегом и digest одновременно. `latest`
не используется: сборка обязана воспроизводиться через месяцы.

## Лицензии

- Данные OpenStreetMap — **ODbL 1.0**. Атрибуция «© OpenStreetMap contributors»

- Формат и инструменты PMTiles — **BSD**.
- Шрифты Noto Sans — **SIL Open Font License 1.1**.
- Спрайты — производные от иконок Tangram, **MIT**.
- planetiler — **Apache-2.0**, Valhalla — **MIT**.

## Порядок сборки

```sh
# 1. Подложка. Файл .osm.pbf скачивается человеком заранее и в Git не кладётся.
./tools/geo/build-basemap.sh \
  --input /data/osm/moscow.osm.pbf \
  --region "Москва и область" \
  --source-date 2026-08-01 \
  --assets /data/basemap-assets \
  --output /data/artifacts/basemap-2026-08-01

# 2. Дорожный граф.
./tools/geo/build-valhalla-graph.sh \
  --input /data/osm/moscow.osm.pbf \
  --output /data/artifacts/valhalla-2026-08-01

# 3. Проверка перед установкой на сервер.
./tools/geo/verify-manifest.sh /data/artifacts/basemap-2026-08-01
```

Каждый набор попадает в собственный каталог с датой в имени и **никогда
не перезаписывается на месте**: приложение может читать текущий набор прямо
сейчас, а подмена файла под ним дала бы обрывок вместо тайла.

## Манифест

`manifest.json` перечисляет каждый файл с размером и SHA-256, а также регион,
границы, дату исходных данных, версии инструментов и SHA-256 входного `.osm.pbf`.
Приложение при старте пересчитывает суммы заново; несовпадение означает
«Карта не настроена», а не попытку продолжить.

## Минимальный набор для проверок

Контрактным проверкам гигабайты не нужны. `make-test-pmtiles.mjs` создаёт
крошечный, но настоящий архив PMTiles v3 без единого сетевого обращения:

```sh
node tools/geo/make-test-pmtiles.mjs /tmp/basemap
```
