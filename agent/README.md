# Агент печати наклеек (Windows)

Печатает наклейки 58×40 мм собранных заказов на термопринтер Xprinter XP-318B,
подключённый по USB.

**Что НЕ проверено вручную.** Физическая печать на XP-318B. Ни один
автоматический тест не может доказать, что бумага вышла из принтера, и мы
этого не изображаем: серверная часть, очередь, протокол и содержимое задания
проверены, USB-печать — нет. Это единственная непроверенная часть, и она
проверяется на настоящей машине с настоящим принтером.

## Как устроено

```
сервер  ──(агент спрашивает раз в 30 с)──▶  ничего нового
        ◀──────── готовое задание TSPL ────  агент  ──▶  спулер Windows (RAW)
        ──────── «передано принтеру» ──────▶
```

- агент ходит **только исходящими** запросами: на компьютере не открывается
  ни один порт;
- раскладку, шрифт и растеризацию делает сервер — агент отдаёт готовые байты;
- один агент обслуживает **один** принтер. Несколько флористов при этом
  пользуются одной точкой печати одновременно: очередь общая;
- задание передаётся спулеру **сырым потоком**, мимо драйвера: драйвер
  пересобрал бы кадр и сместил наклейку на ленте.

## Установка

1. Установите драйвер XP-318B с сайта Xprinter и убедитесь, что принтер виден
   в «Устройства и принтеры».
2. Откалибруйте зазор между наклейками (кнопка подачи на принтере: удерживать
   до автоматической протяжки двух-трёх наклеек). Без калибровки принтер
   выдаёт лишнюю наклейку на каждое задание.
3. Скопируйте `flowers-print-agent.exe` в любую папку, например
   `C:\FlowersPrint\`.
4. В интерфейсе: **Настройки → Печать → Добавить точку**, затем
   **Код подключения**. Код показывается один раз и живёт 15 минут.
5. Запустите `flowers-print-agent.exe` и ответьте на три вопроса: адрес
   сервера, номер принтера из списка, код подключения.
6. Поставьте автозапуск:

   ```powershell
   powershell -ExecutionPolicy Bypass -File install-autostart.ps1 -ExePath C:\FlowersPrint\flowers-print-agent.exe
   ```

## Проверка

- **Настройки → Печать**: точка должна показывать «Онлайн» и имя компьютера.
- Кнопка **Тестовая печать** — из принтера выходит наклейка со словом «ТЕСТ».
- Соберите заказ: наклейка печатается сама, а в очереди печати задание
  становится «Передано принтеру».

«Передано принтеру» — предел того, что известно системе: Windows не сообщает,
вышла ли бумага. Если наклейки нет, повторите печать из карточки заказа.

## Если что-то не так

| Что видно                  | Что это значит                                                              |
| -------------------------- | --------------------------------------------------------------------------- |
| «Нет связи»                | Компьютер выключен, закрыт агент или нет интернета                          |
| «Ошибка»                   | Агент дошёл до принтера и получил отказ; текст ошибки виден в настройках    |
| Задание «требует проверки» | Исход неизвестен: наклейка могла выйти. Посмотрите на принтер и решите сами |

Файлы агента: `%LOCALAPPDATA%\flowers-print-agent\`

- `config.json` — адрес сервера, имя принтера и токен. Токен зашифрован
  средствами Windows под текущего пользователя: файл, унесённый на другой
  компьютер, бесполезен;
- `processed.log` — идентификаторы уже напечатанных заданий. Защита от
  повторной печати после перезапуска;
- `last-error.txt` — последняя ошибка.

## Отладка без принтера

Тот же агент умеет писать задания в файлы вместо спулера — это путь
разработки, а не режим работы:

```bash
node agent/src/agent.cjs --setup     # в качестве принтера указать file:/tmp/labels
node agent/src/agent.cjs
```

Проверяется всё, кроме последнего сантиметра: сам принтер.

## Чего в первой версии нет

MSI, службы Windows, значка в трее, цифровой подписи, автообновления,
нескольких принтеров в одном агенте и определения того, вышла ли бумага
физически. Это осознанные пропуски, а не забытые пункты.
