# Пилотный агент печати для Windows 7 SP1

Отдельная legacy-сборка на **.NET Framework 4.8** для компьютеров под
**Windows 7 SP1**, где современный агент (Node) не запускается.

> **Физическая печать НЕ подтверждена.** Эта сборка — пилотный кандидат.
> Печать на Xprinter под Windows 7 проверяет владелец на настоящем железе;
> до его теста сборка считается непроверенной физически.

## Чем отличается от обычного агента

|               | Обычный агент             | Этот (Win7)                        |
| ------------- | ------------------------- | ---------------------------------- |
| Runtime       | Node 24 (single exe)      | .NET Framework 4.8                 |
| ОС            | Windows 10/11             | Windows 7 SP1 (x86/x64)            |
| Адрес сервера | `https://erpget.ru`       | **только `https://app.erpget.ru`** |
| Файл          | `flowers-print-agent.exe` | `flowers-print-agent-win7.exe`     |

**Почему только `app.erpget.ru`.** Windows 7 не может установить TLS напрямую
с production (`erpget.ru`): у Windows 7 и сервера нет ни одного общего шифра —
Windows 7 умеет только CBC-наборы, а сервер отдаёт только AES-GCM и ChaCha20.
Обратный прокси `app.erpget.ru` принимает CBC-набор, который Windows 7
поддерживает, и ведёт в тот же production и ту же базу. Запасного подключения
к `erpget.ru` у legacy-агента нет — адрес зашит в код.

Всё остальное — то же самое: то же подключение по одноразовому коду, тот же
опрос очереди, тот же готовый TSPL от сервера, та же передача сырым потоком
в **системный Windows Spooler**, то же подтверждение результата, та же защита
от повторной печати. Проверка сертификата HTTPS **не отключается**.

## Требования на компьютере

1. **Windows 7 SP1** (x86 или x64). Без SP1 не работает.
2. **.NET Framework 4.8** — установить с сайта Microsoft (offline-установщик
   поддерживает Windows 7 SP1).
3. **TLS 1.2 включён.** На «чистой» Windows 7 он может быть выключен. Включается
   обновлением **KB3140245** и параметром реестра `SystemDefaultTlsVersions`
   (Microsoft: «Update to enable TLS 1.1 and TLS 1.2 as default secure
   protocols in WinHTTP in Windows»). Агент **не меняет это молча** — только
   покажет инструкцию.
4. **Доверие к корню `ISRG Root X1`.** Обычно он приходит с обновлениями
   Windows. Если нет — установить корневой сертификат ISRG Root X1 в
   «Доверенные корневые центры сертификации» (`certmgr.msc`). Проверку при
   этом **не отключать**.
5. Установленный **драйвер Xprinter XP-318B** и откалиброванный зазор наклеек.

## Установка

1. Скопируйте `flowers-print-agent-win7.exe` в папку, например `C:\FlowersPrint\`.
2. Проверьте окружение:

   ```
   flowers-print-agent-win7.exe --check
   ```

   Команда проверит Windows 7 SP1, .NET 4.8, TLS 1.2 и доверие к ISRG Root X1
   и по каждому пункту скажет «ок» или что исправить. Ничего в системе она
   не меняет.

3. В интерфейсе: **Настройки → Печать → Добавить точку**, затем **Код
   подключения** (действует 15 минут, показывается один раз).
4. Настройте агента:

   ```
   flowers-print-agent-win7.exe --setup
   ```

   Адрес сервера уже зафиксирован (`https://app.erpget.ru`). Выберите принтер
   из списка и введите код подключения.

5. Поставьте автозапуск:

   ```
   install-autostart-win7.cmd C:\FlowersPrint\flowers-print-agent-win7.exe
   ```

6. Запустите агента (или перезагрузитесь — он стартует при входе):

   ```
   flowers-print-agent-win7.exe
   ```

## Проверка (ручная приёмка на Windows 7)

1. **Запуск на Windows 7** — `--check` проходит, агент стартует без ошибок.
2. **Подключение точки** — в **Настройки → Печать** точка «Онлайн», видно имя
   компьютера.
3. **Тестовая этикетка** — кнопка «Тестовая печать»: из принтера выходит
   наклейка со словом «ТЕСТ».
4. **Автоматическая печать после «Собран»** — соберите заказ на точку этой
   смены: наклейка печатается сама.
5. **Правильный статус в ERP** — задание становится «Передано принтеру».
6. **Отсутствие повторной печати** — перезапуск агента и повторный опрос
   не печатают ту же наклейку второй раз.
7. **Автозапуск после перезагрузки** — после reboot и входа агент работает сам.

«Передано принтеру» — предел того, что известно системе: Windows не сообщает,
вышла ли бумага. Если наклейки нет, повторите печать из карточки заказа.

## Файлы агента

`%LOCALAPPDATA%\flowers-print-agent-win7\` (отдельно от обычного агента):

- `config.json` — адрес, имя принтера и токен. Токен зашифрован **DPAPI** под
  текущего пользователя: файл, унесённый на другой компьютер, бесполезен.
- `processed.log` — идентификаторы уже напечатанных заданий (защита от повтора
  после перезапуска).
- `pending.json` — задание, переданное спулеру, но без подтверждения серверу:
  при следующем старте о нём сообщается «исход неизвестен», второй раз оно
  не печатается.
- `last-error.txt` — последняя ошибка. Секреты и токен сюда не пишутся.

## Отладка без принтера

В качестве принтера можно указать `file:C:\labels` — агент будет писать
задания в файлы вместо спулера. Проверяется весь путь, кроме последнего
сантиметра — самого принтера.

## Чего в пилоте нет

MSI, службы Windows, значка в трее, цифровой подписи, автообновления. Это
осознанные пропуски пилота, а не забытые пункты.
