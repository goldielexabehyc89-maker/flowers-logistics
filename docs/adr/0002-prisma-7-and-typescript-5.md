# ADR 0002. Prisma 7.9.1 и TypeScript 5.9.3

**Дата:** 2026-08-04
**Статус:** принято (этап 1, ветка `feat/stage1-foundation`)

## Контекст

Задание называет «Prisma» без версии. Владелец отдельно указал использовать линейку Prisma 7
как текущую стабильную либо оформить отказ от неё как осознанное отклонение с причиной.

## Решение 1: Prisma 7.9.1

Взята версия **7.9.1** — фактический `dist-tag latest` на npm для `prisma`
и `@prisma/client` на дату решения (линейка 6.19.x помечена `prev`). Владелец называл 7.8.0;
это уже не последний патч той же линейки, поэтому взят 7.9.1.

Практические следствия Prisma 7, заложенные сразу:

- генератор `prisma-client` (не legacy `prisma-client-js`) с явным `output`; клиент
  генерируется в `apps/api/src/generated/prisma` и не хранится в Git;
- строка подключения **удалена из `schema.prisma`**: в Prisma 7 `datasource.url` больше
  не поддерживается, конфигурация вынесена в `prisma.config.ts`;
- обязательный driver adapter `@prisma/adapter-pg` вместо Rust query engine;
- Prisma 7 не загружает `.env` автоматически — переменные задаются окружением;
- `openssl` установлен в dev- и production-образы: он нужен schema engine.

Заявленные требования Prisma 7.9.1: Node `^20.19 || ^22.12 || >=24.0` (наш 24.19.0 подходит),
TypeScript `>=5.4.0`.

## Решение 2: TypeScript 5.9.3, а не 7.x

Актуальный `latest` для TypeScript — **7.0.2**, но он **не берётся**.

Причина: `typescript-eslint@8.66.0` объявляет peer-диапазон `typescript >=4.8.4 <6.1.0`.
С TypeScript 7 линтер оказался бы вне поддерживаемого диапазона, а lint входит
в обязательные критические проверки этапа. Взята последняя версия линейки 5 — **5.9.3**,
что также удовлетворяет требованию Prisma (`>=5.4.0`).

Это осознанное отклонение от «всегда последняя версия», а не невнимательность.

**План обновления:** после выхода мажорной версии `typescript-eslint` с поддержкой TypeScript 7
обновить обе зависимости одной задачей, прогнать `typecheck`, `lint`, `build` и критические
тесты. Отдельного продуктового объёма это не затрагивает.

## Альтернативы

- **Prisma 6.19.x.** Отклонено: линейка помечена `prev`, новый проект начинать на предыдущей
  мажорной версии смысла нет.
- **TypeScript 7 + отключить типизированный линтинг.** Отклонено: правила линтера защищают
  от реальных ошибок, отключать их ради версии компилятора — плохой размен.
- **TypeScript 7 + `--force` установка.** Отклонено: нарушенный peer-диапазон даёт непредсказуемое
  поведение линтера и ложные результаты обязательной проверки.
