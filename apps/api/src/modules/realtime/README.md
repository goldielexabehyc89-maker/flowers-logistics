# Модуль `realtime` — realtime-канал

**Статус: не реализован.** Плановый этап: 4 (ветка feat/stage1-realtime-outbox-deploy).

Канал обязан фильтровать события по пользователю и его ролям.

Каталог существует, чтобы граница модуля была зафиксирована в архитектуре.
Кода, заглушечных маршрутов и выдуманных полей здесь нет намеренно:
структура данных определяется только после проверок соответствующего этапа.
