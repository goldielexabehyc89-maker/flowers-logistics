# Модуль `health` — проверки работоспособности

**Статус: реализован (этап 1).**

- `GET /health` — liveness. Отвечает, если процесс жив. Внешние зависимости не проверяются,
  чтобы недоступность БД не приводила к перезапуску контейнера в цикле.
- `GET /ready` — readiness. Проверяет доступность PostgreSQL с ограничением по времени (5 с)
  и отвечает `503`, если база недоступна. На эту пробу ориентируются балансировщик
  и deploy-скрипты.

Тексты ошибок базы наружу не отдаются: строка подключения может содержать пароль.
