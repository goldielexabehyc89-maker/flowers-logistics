# Модуль `users` — пользователи и роли

**Статус: реализован (этап 1, ветка `feat/stage1-auth`).**

Операции: создание, просмотр, изменение, заморозка, разморозка, перевыпуск кода активации,
сброс PIN, история изменений. **Физического удаления нет** — DELETE-маршрутов не существует,
а база дополнительно запрещает удаление триггерами.

- Роли many-to-many; для роли `COURIER` создаётся профиль курьера с транспортом по умолчанию.
- Изменение защищено полем `version`: устаревшая версия возвращает `409`, чужие правки
  не перетираются.
- Смена телефона или ролей отзывает сессии и увеличивает `sessionVersion`.
- Заморозка возможна и для ещё не активированного пользователя. Разморозка возвращает
  `ACTIVE` при наличии PIN и `PENDING_ACTIVATION` без него; отозванные сессии не воскрешают.
- Последний активный администратор защищён: его нельзя заморозить, лишить роли `ADMIN`
  или сбросить ему PIN. Проверка выполняется под advisory-блокировкой и потому устойчива
  к конкурентным запросам.
- Наружу никогда не отдаются `pinHash`, `codeHash`, `tokenHash`, `successorTokenEnc`.
