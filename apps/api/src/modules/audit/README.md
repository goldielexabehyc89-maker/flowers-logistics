# Модуль `audit` — неизменяемый аудит

**Статус: реализован (этап 1, ветка `feat/stage1-auth`).**

Запись аудита создаётся **в той же транзакции**, что и само изменение: невозможны ситуации
«действие выполнено, следа нет» и «след есть, действия не было». Изменение и удаление записей
запрещены триггерами PostgreSQL.

Фиксируются: `ADMIN_BOOTSTRAPPED`, `ACTIVATION_CODE_ISSUED`, `ACTIVATION_CODE_REISSUED`,
`USER_ACTIVATED`, `AUTH_LOGIN_SUCCEEDED`, `AUTH_LOGOUT`, `AUTH_LOGOUT_ALL`,
`AUTH_REFRESH_REUSE_DETECTED`, `USER_CREATED`, `USER_UPDATED`, `USER_ROLES_CHANGED`,
`USER_FROZEN`, `USER_UNFROZEN`, `PIN_RESET`.

Каждая запись содержит автора, снимок его ролей на момент действия, объект, время, источник
и допустимые старое/новое значения. Попытка записать поле с секретным именем (`pin`, `code`,
`token`, `password` и однокоренные) отклоняется на уровне кода до обращения к базе.

История пользователя доступна администратору; логисту — только по доступному ему курьеру.
