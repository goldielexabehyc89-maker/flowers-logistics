# Модуль `couriers` — курьеры

**Статус: базовая часть реализована (этап 1, ветка `feat/stage1-auth`).**

Профиль курьера создаётся вместе с ролью `COURIER` и хранит транспорт по умолчанию
(`CAR` или `FOOT`). Управление курьером выполняется через модуль `users`: отдельного
API у профиля нет, чтобы не раздваивать права и аудит.

Логист управляет только обычными курьерами. Пользователь, которому вместе с `COURIER`
выдана привилегированная роль, логисту недоступен — иначе через «своего курьера»
можно было бы изменить администратора.

Баланс, тарифы и финансовые операции появятся на этапе 7 и здесь сознательно отсутствуют.
