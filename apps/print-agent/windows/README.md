# Печать бланков на локальный принтер

Программа для компьютера, к которому подключён принтер флориста. Она сама
забирает бланки с сервера и печатает их — без вкладок браузера, без «Сохранить
как» и без диалога печати.

## Что она делает

1. Раз в несколько секунд спрашивает сервер: «есть бланк на печать?».
2. Получив задание, скачивает документ и проверяет, что это действительно PDF.
3. **Читает принтер по умолчанию прямо перед печатью.** Не при установке, не
   при привязке — каждый раз заново. Поэтому принтер у станка можно менять в
   Windows как обычно: ни перенастройки, ни звонка администратору не нужно.
4. Сообщает серверу «передаю на печать» **до** того, как отдаст документ
   принтеру, и только потом печатает. Это позволяет системе точно различать
   «бланк точно не печатался» и «бланк, возможно, вышел» — и никогда не
   печатать второй бланк к тому же букету наугад.
5. Сообщает исход: напечатано либо причина отказа.

Если сервер недоступен, программа ждёт и повторяет. Записанный исход печати не
теряется ни при обрыве связи, ни при выключении питания.

## Что нужно на компьютере

- **Windows 10 или 11.**
- **Node.js 24 LTS** — <https://nodejs.org>, пакет `.msi` для Windows.
- **SumatraPDF** — <https://www.sumatrapdfreader.org>. Это бесплатная программа,
  которая умеет печатать PDF молча, без окна. Без неё (или без Adobe Reader)
  печать работать не будет: задания будут отмечаться причиной «не установлена
  программа для печати PDF».

## Установка

1. Установите Node.js и SumatraPDF по ссылкам выше.
2. Скопируйте на компьютер каталог сборки (`dist`) и файл `install.ps1`.
3. Откройте PowerShell **от обычного пользователя** — права администратора
   не нужны — и выполните:

   ```powershell
   .\install.ps1 -SourceDir .\dist -ServerUrl https://адрес-вашего-сервера
   ```

Сценарий скопирует программу в профиль пользователя, пропишет автозапуск при
входе в систему и запустит её. Если Node.js не установлен или слишком старый,
сценарий об этом скажет и ничего делать не станет.

## Привязка рабочего места

Привязка нужна один раз. Она связывает этот компьютер с системой.

1. В системе откройте **Настройки → Печать** (раздел доступен администратору) и
   нажмите **«Подключить компьютер»** — появится код. Он действует **десять
   минут** и показывается один раз: сервер хранит только его отпечаток.
   Потерянный код не восстанавливают, а выпускают заново — прежний при этом
   перестаёт действовать.
2. На компьютере с принтером выполните:

   ```powershell
   node "$env:LOCALAPPDATA\FloristPrintAgent\app\main.js" pair
   ```

3. Введите код. Программа сообщит, что рабочее место привязано.

Код одноразовый: он обменивается на постоянный ключ, который хранится в
зашифрованном виде средствами Windows и доступен только этому пользователю на
этом компьютере. Ни код, ни ключ нигде не показываются и не записываются в
журналы.

Если рабочих мест несколько, **новые задания получает только основное** —
его выбирают в разделе «Настройки → Печать». Остальные ждут своей очереди и
готовы принять роль основного без переустановки.

## Как проверить, что всё работает

Быстрая проверка состояния:

```powershell
node "$env:LOCALAPPDATA\FloristPrintAgent\app\main.js" status
```

Ответ покажет адрес сервера, выполнена ли привязка и какой принтер выбран в
Windows прямо сейчас.

Настоящая проверка — **тестовая печать**: в разделе «Настройки → Печать»
нажмите **«Тестовая печать»**. Из принтера должна выйти страница с надписью
«Это тестовая страница». Она идёт той же очередью и тем же путём, что и
настоящие бланки, поэтому её успех означает, что заработают и они.

Окно программы (оно открывается при входе в систему и его можно свернуть)
всё время показывает: есть ли связь, имя рабочего места, текущий принтер,
последнее задание и последнюю ошибку.

## Частые сообщения

| Сообщение                                 | Что сделать                                                                             |
| ----------------------------------------- | --------------------------------------------------------------------------------------- |
| «Не выбран принтер по умолчанию»          | Выбрать принтер по умолчанию в параметрах Windows.                                      |
| «Принтер не отвечает»                     | Проверить питание и кабель, снять галочку «Работать автономно».                         |
| «Не установлена программа для печати PDF» | Установить SumatraPDF.                                                                  |
| «Нет связи с сервером»                    | Проверить сеть. Задания не теряются, печать продолжится сама.                           |
| «Рабочее место отключено администратором» | Получить новый код и выполнить привязку заново. Программа при этом продолжает работать. |

## Удаление

```powershell
.\uninstall.ps1
```

Сценарий останавливает автозапуск, удаляет файлы и **удаляет сохранённый ключ**
(«отвязать рабочее место»). После этого обязательно отзовите устройство в
разделе «Настройки → Печать»: удаление файлов на компьютере само по себе не
отменяет его прав на сервере.

Если удаление нужно только ради обновления, добавьте `-KeepData` — настройка и
привязка сохранятся.

## Честные ограничения этого выпуска

Это первый рабочий выпуск, и он сознательно упрощён:

- **Требуется установленный Node.js 24.** Своего исполняемого файла у программы
  пока нет — она запускается через Node. Сборка в один `.exe` (Node SEA) и
  установщик `.msi` с автообновлением — следующий шаг, и он же снимет
  требование ставить Node вручную.
- **Требуется SumatraPDF (или Adobe Reader).** Windows не умеет печатать PDF без
  диалога своими средствами, поэтому нужна вспомогательная программа.
  SumatraPDF рекомендуется: она бесплатна, ставится без прав администратора и
  печатает молча.
- **Автозапуск — задача планировщика при входе пользователя, а не служба.**
  Это сделано намеренно (служба потребовала бы прав администратора и видела бы
  не тот принтер, что человек за компьютером), но означает: пока никто не вошёл
  в систему, печать не идёт.
- **Обновление — переустановка** тем же сценарием `install.ps1`. Привязка при
  этом сохраняется.
